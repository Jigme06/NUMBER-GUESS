NUMBER GUESSING GAME: CMPSC 132 FINAL PROJECT

This is an interactive, terminal based Number Guessing Game developed in Python.
The user is challenged to guess a number randomly generated between 1 and 100 within a specific number of attempts based on the difficulty level selected.

KEY FEATURES:
- Difficulty Scaling: Five Distinct difficulty modules displaced ranging from 1 to unlimited attempts
- Data Normalizaion: As far as possible,invalid user input will be tried to be corrected preventing program from crashing.
- Session Tracking: For one execution session, stores Personal Best for all users.
- Mid Game Exit: 999 is a value which the user can input allowing users to forfeit a round without having to exit the terminal completely

STEPS TO RUN
Download the File: Save the source code as final_project.py.

Open Terminal/Command Prompt: Navigate to the folder where you saved the file.

Execute the Script: Run the following command:
           python final_project.py

Play the Game:

1. Enter your name when prompted.
2. Select a difficulty level from the displayed list.
3. Input your guesses. If you wish to give up, type 999.
4. Follow the on-screen prompts to replay as the same user, switch users, or exit to view the final Score Leaderboard.
